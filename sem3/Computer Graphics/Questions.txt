1.  a.  Discuss video controller refresh operation with a neat diagram.
        If on average, it takes 20 ns for a video controller to access a

                                      OR

        Define computer graphics. Explain the applications of computer
        graphics in Computer Simulation, Scientific Visualization, and CAD.

    b.  Define CRT. Explain with a neat diagram the working principle of
        the Shadow Mask method.


2.  a.  What is the difference between DDA and Bresenham's Line Algorithm?
        Discuss the "Midpoint Circle Drawing Algorithm" for 8 octants.
        Derive an expression for the decision parameter for the conditions
        mentioned below:
            i.   Initial decision parameter P₀.
            ii.  Decision parameter, when Pₖ < 0.
            iii. Decision parameter, when Pₖ > 0.

    b.  Explain the Boundary Fill algorithm in detail. How does this
        approach differ from Flood Fill?


3.  a.  Differentiate between window and viewport. Discuss the
        2-Dimensional Viewing Pipeline with the different steps involved.
        Further derivation is needed for the window-to-viewport coordinate
        transformation.

    b.  A mirror is placed vertically such that it passes through the
        points (5, 0) and (0, 5). Find the reflected view of triangle ABC
        with coordinates A(5, 30), B(30, 50), C(20, 60).

                                      OR

        What is the significance of clipping in computer graphics? Let ABCD
        be the rectangular window A(20, 20), B(90, 20), C(90, 70), and
        D(20, 70). Find the region code for the end points and use the
        Cohen-Sutherland line clipping algorithm to clip the line P₁P₂
        with P₁(10, 30) and P₂(80, 90).


4.  a.  Discuss the difference between spline approximation curve versus
        an interpolation curve. Derive an expression for perspective
        projection with the necessary diagram.

    b.  Derive the equation for the cubic Bezier curve and find the
        coordinate at t = 0.2 with respect to the control points (1, 1),
        (4, 6), (8, −3), and (12, 2).


5.  a.  Why is the Depth Sorting method called Painter's Algorithm?
        Explain the Scan Line method for visible surface detection with
        an example.

    b.  What is the difference between specular reflection versus diffuse
        reflection? Briefly explain polygon surface shading methods.


6.  a.  Discuss the need for machine-independent graphical languages.
        Explain two different graphical software standards.

    b.  What is the significance of OpenGL in computer graphics? Discuss
        the Open Graphics Library in detail with the different features
        associated with it.


7.  Write short notes on (any TWO):
        i.   Raster vs. Random Scan System
        ii.  Graphics File Formats
        iii. Color Models
